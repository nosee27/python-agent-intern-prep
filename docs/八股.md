## 1. 深拷贝和浅拷贝区别？
**答**：浅拷贝复制对象引用，深拷贝递归复制所有嵌套对象。

**项目举例**：Agent的history列表用`copy.deepcopy()`避免多会话间上下文污染，否则修改一个会话会影响另一个。

## 2. 列表推导式和生成器表达式区别？
**答**：列表推导式立即生成完整列表（占内存），生成器表达式惰性求值（省内存）。

**项目举例**：处理日志文件时用生成器逐行读取`for line in open(f)`，而不是`readlines()`，避免大文件内存爆炸。

## 3. PEP8是什么？你项目里怎么遵守的？
**答**：PEP8是Python代码风格指南。

**项目举例**：我用black自动格式化，函数名用小写下划线，行宽不超过88字符，import按标准库/第三方/本地分组。
## 4. is 和 == 区别？
**答**：`==` 比较值是否相等，`is` 比较内存地址是否相同（是否是同一个对象）。

**项目举例**：Agent的history列表我判断 `if history is None` 用is，因为None是单例；判断内容是否相等用 `==`。

## 5. *args 和 **kwargs？
**答**：`*args` 接收多余的位置参数（元组），`**kwargs` 接收多余的关键字参数（字典）。

**项目举例**：我的 `chat()` 函数定义 `def chat(message, history=None, **kwargs)`，方便扩展system、model等参数而不改签名。

## 6. 什么是闭包？装饰器为什么能工作？
**答**：闭包是内部函数引用外部函数的变量，即使外部函数已执行完毕。装饰器本质是闭包：外层函数接收被装饰函数，内层函数添加额外逻辑后调用原函数。

**项目举例**：我自己写计时装饰器时，外层接收func，内层wrapper记录时间、调用func、返回结果，这就是闭包。
